# Dynamic-fDES-with-LDP-Research
Overview

This repository contains the MATLAB implementation, experimental scripts, and results for our Dynamic Fuzzy Differential Evolution Strategy (fDES) research project.

The project focuses on implementing and evaluating the methodology described in the reference research paper, including experiments involving RR-interval signals and Laplace-related analysis where applicable.

Repository Structure

matlab/ — MATLAB scripts and supporting functions.

data/ — Permitted test data or instructions for obtaining the original datasets.

results/ — Numerical outputs, experimental summaries, and CSV files.

figures/ — Graphs and plots generated by the experiments.

docs/ — Supplementary reports and documentation.
